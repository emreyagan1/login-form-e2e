# Login Formu E2E Testi

Vite + React ile hazırlanmış login formu ve Cypress E2E testleri (Workintech gün projesi).

## Kurulum

```bash
npm install
npm run dev        # http://localhost:5173
```

## Testler

```bash
npm run cy:open    # Cypress arayüzü (önce `npm run dev` çalışıyor olmalı)
npm run test:e2e   # dev sunucuyu açar, testleri headless çalıştırır, kapatır
```
